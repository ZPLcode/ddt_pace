# DDT D1: data collection and fitting

The D1 task uses the public `DDTRobot/ddt_ros2_control` submodule for its URDF.
After cloning this repository, initialize the submodule:

```bash
git submodule update --init --recursive
```

The URDF is then at
`third_party/ddt_ros2_control/urdfs/d1_description/urdf/robot.urdf`.
It identifies the 12 position-controlled hip, thigh, and calf joints. The four
velocity-controlled wheel joints remain in the articulation but are excluded from
the stock PACE objective.

Generate a synthetic dataset to validate the setup:

```bash
python scripts/pace/d1_data_collection.py --headless
```

For D1, all 12 leg joints receive the chirp simultaneously. Left/right hip
targets and front/rear sagittal targets use mirrored signs to cancel the
dominant base wrench, following PACE's symmetric-excitation requirement. The
synthetic and real-robot targets use a 20-second, 0.1–4 Hz chirp with 0.08 rad
hip and 0.12 rad thigh/calf amplitudes. Both use the folded pose with hips
spread outward to clear the chassis support. The real-robot collector shifts
each target center at handoff to preserve the measured holding torque.

For real-robot identification, pass the converted `.pt` file to `fit.py` with
`--data-file`. The file contains `time`, `dof_pos`, and `des_dof_pos`. The two position
tensors must have shape `[T, 12]`, sampled at 400 Hz, in this order:

```text
FL_hip_joint, FL_thigh_joint, FL_calf_joint,
FR_hip_joint, FR_thigh_joint, FR_calf_joint,
RL_hip_joint, RL_thigh_joint, RL_calf_joint,
RR_hip_joint, RR_thigh_joint, RR_calf_joint
```

For real-robot collection, support the D1 chassis securely. The script first
folds all four legs slowly to clear the wheels from the ground. Wheel contact
can block leg motion and invalidate actuator data. The standalone C++ program uses
the installed D1 `ddt_hardware` library and the robot's
`d1` configuration. The wrapper stops `d1_command.service` and
`d1_bringup.service`, then refuses to run if another `ros2_control_node`
is active.

Verify communication with a small motion before recording:

```bash
./scripts/pace/run_d1_hardware_chirp.sh --test
```

This takes 10 s to fold the legs toward the D1 `transform_down` pose, with
hips at ±0.3 rad and calves at -2.50 rad. It holds that pose for 3 s so the
operator can see whether the legs and wheels clear the support; press Ctrl+C
if they touch. It holds `FL_hip_joint` for another 1 s, moves it by
0.08 rad over 4 s, and returns over 4 s. After a successful test, it takes
10 s plus a 1 s hold to return all legs to their measured starting pose. It
prints target angle, measured angle, velocity, and torque.
The fold uses the `transform_down` joint gains and zero feedforward, with a
20 Nm proportional effort cap. It stops on large tracking error, velocity,
torque, or stale feedback. Before switching to `kp=60`, `kd=2`, the script
shifts each position target to preserve its measured holding torque. The hip
test stops if feedback speed exceeds 0.25 rad/s or torque exceeds 18 Nm. The other legs hold
their folded angles, and the wheels receive zero gains. The chassis must remain
supported throughout. If a safety check stops motion, the script releases motor
gains and may leave the legs folded; inspect the robot before restarting.
The D1 driver sends commands in four-motor leg frames, so all four slots in
each leg are included.
The test does not create a PACE dataset.

```bash
./scripts/pace/run_d1_hardware_chirp.sh
```

The script compiles the collector and writes a timestamped CSV under
`data/d1_real/`. Copy the printed CSV path to the PACE
machine and convert it to a `.pt` file with the same timestamp:

```bash
python scripts/pace/d1_csv_to_pt.py data/d1_real/chirp_YYYYMMDD_HHMMSS.csv
```

The collector folds the legs, runs a 400 Hz, 20 s chirp on the 12 leg joints in
the folded pose, then returns to the starting pose. It logs actual joint angles
and sent targets. It uses 60/2 leg PD gains during the chirp;
the four wheels receive zero velocity and no position stiffness. The recording
stops if measured joint speed exceeds 4 rad/s or feedback
torque exceeds 20 Nm. The converter
checks that all 8000 samples were recorded and resamples to PACE's 400 Hz grid.

Run the fit on the PACE machine. The 4096-environment setting was used for the
D1 fit; reduce it if GPU memory is limited:

```bash
python scripts/pace/fit.py --task Isaac-Pace-D1-v0 --data-file data/d1_real/chirp_YYYYMMDD_HHMMSS.pt --num_envs 4096 --headless
```

Results are written to a timestamped folder under `logs/pace/d1_sim/`.
